# 🚀 Unit3Dup-AST | نسخة فريق المصدر العربي المطورة


**أداة الرفع الآلي وتوليد التورنت المخصصة لفريق AST وتراكر UNIT3D.**

---

## 🌟 لماذا هذه النسخة؟ (المميزات الحصرية)
تختلف هذه النسخة عن المشروع الأصلي بوجود **"نظام الانتباه الذكي"** الذي تم تطويره ليلائم المحتوى العربي:

1.  **التصنيف الآلي الدقيق:** توزيع الملفات تلقائياً (كرتون مدبلج، مترجم، وثائقي، مسرحيات، إلخ) بناءً على قواعد الفريق.
2.  **الفحص التقني العميق:** يقرأ البوت ملفات الفيديو (MediaInfo) للتأكد من وجود الصوت العربي والترجمة قبل تحديد القسم المناسب.
3.  **البحث المزدوج (Double-Match):** إذا فشل البحث كفيلم، يعيد المحاولة تلقائياً كـ (TV Series) والعكس، وهو مثالي للوثائقيات والمحتوى المربك.
4.  **حماية الكلمات الحساسة:** يحمي الكلمات القصيرة الهامة في البحث (مثل **Us** و **80s**) من الحذف.
5.  **توقيع فريق AST:** إضافة توقيع الفريق بشكل منسق وجميل في وصف كل تورنت.

## 📋 تنبيهات بخصوص ضبط ملف الإعدادات `Unit3Dbot.json`

### 1) إعداد بيانات التراكر (API Key و PID)
لتهيئة بيانات حسابك في التراكر داخل البوت:

1. ادخل إلى **إعداداتي** في التراكر.
2. من أعلى القائمة اختر **الإعدادات**.
3. من القائمة المنسدلة اختر **مفتاح API**.
4. اضغط **إنشاء** ثم انسخ المفتاح (API Key).
5. افتح ملف الإعدادات `Unit3Dbot.json` والصق المفتاح في الحقل المخصص.

وبخصوص **معرف التورنت `pid`**:

1. ادخل إلى **الملف الشخصي**.
2. من أسفل الصفحة اختر **إظهار pid**.
3. انسخ قيمة `pid` ثم ضعها في ملف `Unit3Dbot.json` في الحقل المخصص.

مثال تنسيقي داخل `tracker_config`:

```json
"tracker_config": {
  "TMDB_APIKEY": "your_tmdb_api_key",
  "TVDB_APIKEY": "your_tvdb_api_key",
  "TVDB_PIN": "your_tvdb_pin",
  "AST_KEY": "your_tracker_api_key",
  "AST_PID": "your_pid"
}
```

> **ملاحظة:** الأسماء أعلاه للتوضيح، استخدم المفاتيح الفعلية كما هي معرفة داخل ملف الإعدادات لديك.

### 2) ضبط بيانات مركز الرفع الداخلي
لضبط الربط مع مركز الرفع الداخلي:

1. ادخل إلى **مركز الرفع الداخلي** باستخدام **اسم المستخدم** و**كلمة المرور** الخاصة بمركز الرفع.
2. انتقل إلى صفحة الملف الشخصي:
   `https://arabicsource.net/U/?profile`
3. انسخ قيمة **Key**.
4. افتح `Unit3Dbot.json` وضع:
   - **اسم المستخدم الخاص بمركز الرفع**
   - **المفتاح (Key) الخاص بمركز الرفع**

مثال تنسيقي:

```json
"tracker_config": {
  "ASTU_KEY": "your_upload_center_key",
  "ASTU_USERNAME": "your_upload_center_username"
}
```

> **تنبيه مهم:** ملف الإعدادات يتم إنشاؤه تلقائياً، ومساره على ويندوز:
> `C:\Users\[USER]\AppData\Local\Unit3Dup_config`

## 🛠️ التثبيت والتحديث (Installation)

للأعضاء الجدد، استخدم الأمر التالي في **PowerShell** أو **Terminal**:

```bash
pip install git+https://github.com/harment/Unit3Dup-AST.git
```

للترقية والحصول على آخر التحديثات:

```bash
pip install git+https://github.com/harment/Unit3Dup-AST.git --upgrade
```

### إزالة التنصيب

لإزالة الحزمة من النظام استخدم:

```bash
pip uninstall Unit3Dup-AST
```

> قد يطلب منك pip تأكيد الإزالة، وعندها اكتب `y` ثم اضغط Enter.

## 🛠️ متطلبات التشغيل على ويندوز (Windows Setup)

لضمان عمل البوت بكفاءة (استخراج الصور، فحص جودة الفيديو، والرفع)، يجب تثبيت الأدوات التالية:

### 1️⃣ تثبيت وتفعيل FFmpeg (ضروري جداً)
يعتبر **FFmpeg** المحرك الأساسي لاستخراج الصور وتحليل ملفات الفيديو.
1. قم بتحميل النسخة الجاهزة من [هذا الرابط المباشر](https://gyan.dev).
2. فك الضغط عن المجلد وانقله إلى القرص `C:\` وقم بتسميته `ffmpeg`. (المسار يجب أن يكون `C:\ffmpeg`).
3. **إضافة المسار للـ Path:**
   - ابحث في قائمة "ابدأ" عن **"Edit the system environment variables"**.
   - اضغط على **Environment Variables**.
   - في الأسفل عند **System variables**، ابحث عن سطر **Path** واضغط **Edit**.
   - اضغط **New** وأضف هذا المسار: `C:\ffmpeg\bin`.
   - اضغط **OK** في جميع النوافذ.
4. **اختبار النجاح:** افتح نافذة PowerShell جديدة واكتب `ffmpeg -version`.

---

### 2️⃣ تثبيت Git (للتنصيب والتحديث التلقائي)
يجب تثبيت Git لتتمكن من تحميل البوت وتحديثه بأمر واحد.
1. حمل البرنامج من [الموقع الرسمي](https://git-scm.com).
2. أثناء التثبيت، تأكد من بقاء خيار **"Add to PATH"** مفعلاً.
3. افتح نافذة PowerShell جديدة واكتب `git --version` للتأكد.

---

### 3️⃣ تثبيت Poppler (لملفات الـ PDF فقط)
إذا كنت تنوي رفع كتب أو وثائق بصيغة PDF لاستخراج الأغلفة تلقائياً:
1. حمل الأداة من [هنا](https://github.com/oschwartz10612/poppler-windows/releases/)
2. فك الضغط وأضف مجلد الـ `bin` الخاص بها إلى الـ **Path** بنفس طريقة FFmpeg (مثال: `C:\poppler\bin`).

---

> ⚠️ **تنبيه هام:** بعد إضافة أي مسار للـ **Path**، يجب إغلاق نافذة الـ PowerShell وفتحها من جديد لكي يتعرف النظام على الأدوات.

### 🐧 لينكس (Ubuntu/Debian)

```bash
sudo apt install ffmpeg poppler-utils
```

## 🚀 طريقة التشغيل (Usage)

| الأمر | الوظيفة |
| :--- | :--- |
| `unit3dup -u "path/to/file"` | لرفع ملف واحد فقط |
| `unit3dup -f "path/to/folder"` | لرفع مجلد كامل |
| `unit3dup -scan "path/to/folder"` | لفحص مجلد ورفع محتوياته آلياً |
