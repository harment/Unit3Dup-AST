# 🚀 Unit3Dup-AST | نسخة فريق المصدر العربي المطورة


**أداة الرفع الآلي وتوليد التورنت المخصصة لفريق AST وتراكر UNIT3D.**

---

## 🌟 لماذا هذه النسخة؟ (المميزات الحصرية)
تختلف هذه النسخة عن المشروع الأصلي بوجود **"نظام الانتباه الذكي"** الذي تم تطويره ليلائم المحتوى العربي:

1.  **التصنيف الآلي الدقيق:** توزيع الملفات تلقائياً (كرتون مدبلج، مترجم، وثائقي، مسرحيات، إلخ) بناءً على قاعدة بيانات التراكر.
2.  **الفحص التقني العميق:** يقرأ البوت ملفات الفيديو (MediaInfo) للتأكد من وجود الصوت العربي والترجمة قبل تحديد القسم.
3.  **البحث المزدوج (Double-Match):** إذا فشل البحث كفيلم، يعيد المحاولة تلقائياً كـ (TV Series) والعكس، وهو مثالي للوثائقيات.
4.  **حماية الكلمات الحساسة:** يحمي الكلمات القصيرة الهامة في البحث (مثل **Us** و **80s**) من الحذف.
5.  **توقيع فريق AST:** إضافة توقيع الفريق بشكل منسق وجميل في وصف كل تورنت.

---

## 🛠️ التثبيت والتحديث (Installation)

للأعضاء الجدد، استخدم الأمر التالي في **PowerShell** أو **Terminal**:

```bash
pip install git+https://github.com/harment/Unit3Dup-AST.git
```
للترقية والحصول على آخر التحديثات:
```bash
pip install git+https://github.com/harment/Unit3Dup-AST.git --upgrade
```

## 🛠️ متطلبات التشغيل على ويندوز (Windows Setup)

لضمان عمل البوت بكفاءة (استخراج الصور، فحص جودة الفيديو، والرفع)، يجب تثبيت الأدوات التالية:

### 1️⃣ تثبيت وتفعيل FFmpeg (ضروري جداً)
يعتبر **FFmpeg** المحرك الأساسي لاستخراج الصور وتحليل ملفات الفيديو.
1. قم بتحميل النسخة الجاهزة من [هذا الرابط المباشر](https://gyan.dev).
2. فك الضغط عن المجلد وانقله إلى القرص `C:\` وقم بتسميته `ffmpeg`. (المسار يجب أن يكون `C:\ffmpeg`).
3. **إضافة المسار للـ Path:**
   - ابحث في قائمة "ابدأ" عن **"Edit the system environment variables"**.
   - اضغط على **Environment Variables**.
   - في الأسفل عند **System variables**، ابحث عن سطر **Path** واضغط **Edit**.
   - اضغط **New** وأضف هذا المسار: `C:\ffmpeg\bin`.
   - اضغط **OK** في جميع النوافذ.
4. **اختبار النجاح:** افتح نافذة PowerShell جديدة واكتب `ffmpeg -version`.

---

### 2️⃣ تثبيت Git (للتنصيب والتحديث التلقائي)
يجب تثبيت Git لتتمكن من تحميل البوت وتحديثه بأمر واحد.
1. حمل البرنامج من [الموقع الرسمي](https://git-scm.com).
2. أثناء التثبيت، تأكد من بقاء خيار **"Add to PATH"** مفعلاً.
3. افتح نافذة PowerShell جديدة واكتب `git --version` للتأكد.

---

### 3️⃣ تثبيت Poppler (لملفات الـ PDF فقط)
إذا كنت تنوي رفع كتب أو وثائق بصيغة PDF لاستخراج الأغلفة تلقائياً:
1. حمل الأداة من [هنا](https://github.com).
2. فك الضغط وأضف مجلد الـ `bin` الخاص بها إلى الـ **Path** بنفس طريقة FFmpeg (مثال: `C:\poppler\bin`).

---

> ⚠️ **تنبيه هام:** بعد إضافة أي مسار للـ **Path**، يجب إغلاق نافذة الـ PowerShell وفتحها من جديد لكي يتعرف النظام على الأوامر الجديدة.


### 🐧 لينكس (Ubuntu/Debian)
```bash
sudo apt install ffmpeg poppler-utils
```

## 🚀 طريقة التشغيل (Usage)


| الأمر | الوظيفة |
| :--- | :--- |
| `unit3dup -u "path/to/file"` | لرفع ملف واحد فقط |
| `unit3dup -f "path/to/folder"` | لرفع مجلد كامل |
| `unit3dup -scan "path/to/folder"` | لفحص مجلد ورفع محتوياته آلياً |
